### 3. 비용 집계 구조 재설계

**배경**: `~/.claude/metrics/costs.jsonl`이 항상 `session_id: "default"`, `model: "unknown"`, 전량 0으로 기록됨을 확인. Claude Code 바이너리가 구조체를 쓰지만 값을 채우지 않는 미구현 상태.

**해결:**
- **서버**: `GET /api/sessions/:sessionId/cost` 엔드포인트 추가
  - JSONL에서 `assistant` 이벤트의 `usage` 필드 직접 합산
  - Sonnet 4.6 단가 적용 후 `estimatedCostUsd` 반환
- **사이드바**: 프로젝트 펼칠 때 해당 세션들 비용 병렬 fetch
  - `$X.XX` / `<$0.01` 형식으로 각 세션 우측 표시
- **Cost 탭 제거**: costs.jsonl 참조 섹션이 무의미해 탭 전체 삭제
- **대화 탭**: 각 Agent 턴에 `TurnUsage` 집계 (inputTokens, outputTokens, cacheWrite, cacheRead, estimatedCostUsd)

### 5. 비어있을 때 대시보드 (WelcomeDashboard)

**파일**: `client/src/components/WelcomeDashboard.tsx`

세션 미선택 시 탭 대신 비용 가이드 대시보드 표시.
Jeff Dean "Latency Numbers Every Programmer Should Know" 형식 차용.

**구성:**
1. **모델 토글** (Haiku 4.5 / Sonnet 4.6 / Opus 4.8) — 선택 시 전체 비용 수치 동적 재계산
2. **단가 카드 4종** — Input / Cache Write / Output / Cache Read (로그 스케일 바)
3. **연산별 비용 테이블** — 5개 섹션, 각 행에 토큰 추산 + 비용 범위 + 로그 스케일 바
   - 토큰화 기초 / 도구 호출 / 컨텍스트 주입 / 에이전트 / 캐시 효과
4. **핵심 법칙 6개 카드** — 모델별 수치 자동 반영

**비용 계산 구조**: `costFn: (ModelPricing) => { low, high }` 함수를 각 row에 정의. 모델 변경 시 O(1)로 전체 재계산.
