## 파일시스템 결합 3지점과 해소

1. **`scanner/index.ts`** — `homedir()` 하드코딩 + `resolveProjectPath()` 가 실제 FS 를
   `/`부터 걸어 역디코딩. → 로직을 `shared/project-path.ts` 로 분리(pricing.ts 패턴),
   `scanSessions()` 에 `manifest.json` 우선 조회 추가. 로컬은 FS-walk 폴백 유지.
2. **`watcher/index.ts`** — `CLAUDE_PROJECTS` 하드코딩. → `startWatcher(broadcast, baseDir?)` 파라미터화.
3. **`index.ts`** — `127.0.0.1` 바인딩 + CORS localhost 전용. → `DATA_DIR`/`PORT`/`HOST`/
   `ALLOWED_ORIGIN`/`AUTH_TOKEN` env 배선. 미설정 시 기존 동작(단 AUTH_TOKEN 은 필수).

> **핵심 함정**: 클라우드엔 `/Users/...` 실제 디렉토리가 없어 `resolveProjectPath()` 가
> 라벨을 뭉갠다. `filePath` 는 baseDir 기준이라 무사. → sync 잡이 로컬에서 만든
> `manifest.json`(encoded→실제경로)을 서버가 우선 조회하도록 우회.

  **DELETE 없음**(additive-only 방어선). 경로 세그먼트 traversal 검사 + 임시파일 rename 원자적 쓰기.
  ※ 서브에이전트 라우트는 플래너 계획에 없었으나 비용 집계 정확도 위해 추가.

  localStorage 런타임 저장 — 번들에 시크릿 안 남김), `SessionTitleBadge.tsx`.
  하드코딩 `localhost` 4곳 교체.
- **로컬 잡 `sync/`**: `generate-manifest` / `generate-summaries` / `upload-sessions`(mtime diff, additive).
  `core.ts` 순수 로직 + `http.ts`/`state.ts` I/O 분리. launchd plist + run.sh.

  ⚠️ `claude -p` 는 자체 세션을 남기므로 전용 `~/.claude-observer/summarizer` 에서 실행하고
  해당 세션(`filePath.startsWith(SUMMARIZER_DIR)`)은 요약 대상에서 제외해 재귀 방지.
